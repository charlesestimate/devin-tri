# Human test sets — cover note for Karl

Three instruction sets follow. Each is self-contained and can be handed to the tester as-is. They cover what the browser agent cannot do: a real phone on a real site with no signal, a camera, a printed Quick Response code, a physical delivery and a physical stock count, a second human approving a first human's request, and the judgement of someone who does this work today and can say whether the platform fits it.

| Set | Who | Where | Time |
|---|---|---|---|
| **A — Field pair** | one Person In Charge and one Safety Officer, each on their own Android phone | a real site or any place with weak signal, plus airplane mode | about 3 hours over one day |
| **B — Finance and Payroll** | the Head of Finance, or a Finance officer and the payroll officer together | office | about 3 hours |
| **C — Procurement and Warehouse** | the Procurement Head and the Laguna warehouse custodian | office plus the Laguna warehouse | about 3 hours |

## Before you hand these out

The sets use the data the browser agent creates in Phase 1 to Phase 6 of its brief. **Hand out the sets only after the agent has reported through Phase 6**, so projects P1 to P5, the crew, the warehouses and the first site reports exist.

Then do these yourself as console holder:

1. **Accounts.** Create one account per tester and link each to a person record. Assign the role named at the top of each set. Assigning a role raises gate 24 (department head primary, Chief Operating Officer alternate); approve it. Each tester's sign-in must show the Magnus tenant, not "pending tenant assignment".
2. **Project P2, Lipa Cold Storage and Logistics Inc., is the field project for Set A.** The agent leaves P2 active but not mobilised. On P2: attach an insurance certificate document, mobilise, record the Construction Safety and Health Program approval, and start block B0. Do **not** file any site report on P2 and do not start B1. Set A does the rest.
3. **Site emergency card for the P2 site.** Fill it in (nearest hospital, ambulance number, evacuation point, first aiders, client contact). Set A checks it offline.
4. **Quick Response code for the P2 site.** Open the P2 site's near-miss form code and print it, or be ready to show it on a screen. Set A scans it from a phone that is not signed in.
5. **Set A's Safety Officer must be the Safety Officer of record on P2.** Gates 28 and 29 have no alternate.
6. **Set B needs one payroll period** that covers the three P1 site-report days the agent filed plus at least one working day with no report. Do not create it yourself; the tester creates it, but confirm the rate tables (Social Security System, PhilHealth, Pag-IBIG, withholding) have at least the rows the agent entered.
7. **Set C needs a real delivery.** Pick a supplier delivery that is actually due at Laguna within the test week, or use any incoming box with a delivery receipt. The custodian receives it against a purchase order the Procurement Head raises in the set.

## Rules that apply to all three sets

- Every record a tester creates is named with the prefix on the set: `HT-A`, `HT-B` or `HT-C`. That is how the three human reports and the agent's report are separated afterwards.
- Testers never delete anything, and never edit a record they did not create unless the step says so.
- Each set ends with a report template. Ask for the report as a Word or Google document with numbered screenshots, within two days of the test.
- When the three reports and the agent's report are in, send all four to me and I will consolidate them into the Hercules fix prompt.
